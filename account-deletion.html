HARU 계정 및 데이터 삭제 요청

앱 이름: HARU (하루)
개발자: (주)한국마이크로시스템
최종 업데이트: 2026년 4월 15일

HARU는 사용자의 데이터 통제권을 존중합니다. 계정 및 데이터 삭제는 아래 두 가지 방법 중 편하신 방법으로 요청하실 수 있습니다.

방법 1. 앱 내에서 직접 삭제 (권장)

  1. HARU 앱 실행 후 로그인
  2. 하단 탭 "설정" 선택
  3. "계정 관리" 항목으로 이동
  4. "계정 삭제" 선택
  5. 안내 확인 후 "탈퇴" 입력하여 최종 확인

※ 이 방법은 즉시 삭제되며 별도의 검토 절차가 없습니다.

방법 2. 이메일로 요청

앱을 이미 삭제하셨거나 직접 처리가 어려운 경우, 아래 이메일로 요청해주세요.

이메일: info@microsystem.co.kr
제목: [HARU] 계정 삭제 요청
본문에 포함할 정보:

  • HARU 가입 이메일
  • 삭제 요청 사유 (선택)

※ 본인 확인을 위해 가입 시 사용한 이메일에서 발송해주세요.

처리 기간

  • 방법 1 (앱 내 삭제): 즉시 처리
  • 방법 2 (이메일 요청): 영업일 기준 최대 7일 이내

삭제되는 데이터

계정 삭제 시 아래 모든 데이터가 영구적으로 삭제되며 복구할 수 없습니다.

구분 항목
계정 정보 이메일, 이름, 비밀번호 해시, 인증 정보
일기 데이터 모든 일기 본문, 제목, 요약, 대화 기록, 감정 색상, 태그
이미지 일기에 첨부한 사진, 일기장 표지, 프로필 아바타
커뮤니티 프로필, 댓글, 좋아요, 리액션, 팔로우, 북마크, 차단 목록
설정 테마, 음성, 알림, 사용자 정보 등 모든 환경설정
AI 기억 데이터 장기기억(LTM), 단기기억(STM)
약관 동의 이력 동의 일시 및 버전 기록
알림 기록 받은 알림 전체

법령에 따라 보관되는 데이터

관련 법령에 따라 일부 데이터는 일정 기간 동안 익명화된 형태로 보관될 수 있습니다.

항목 보관 기간 근거 법령
서비스 접속 로그 (IP, 접속 일시) 3개월 통신비밀보호법
부정 이용 방지를 위한 익명 로그 최대 90일 회사 내부 정책

위 보관 데이터는 개인을 식별할 수 없는 형태로만 유지되며, 보관 기간 만료 시 자동으로 영구 삭제됩니다.

일부 데이터만 삭제하고 싶은 경우

계정을 유지하면서 일부 일기/이미지만 삭제하길 원하시면 앱 내에서 직접 삭제할 수 있습니다.

  • 개별 일기 삭제: 일기 상세 화면 → 삭제
  • 일기장 통째로 삭제: 일기장 설정 → 삭제 (일기 + 이미지 함께 삭제)
  • 이미지만 삭제: 일기 편집 → 이미지 제거 → 저장
  • 커뮤니티 활동만 삭제: 댓글 길게 누름 → 삭제 / 프로필 편집
